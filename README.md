# jZietflow
    jZ is a Java desktop app for managing the 
    work, projects, tasks, planning and content
    of a solo developer.

## Status
    Early Development - Version 0.1.0

## Technology
    -> Java
    -> JavaFX
    -> Maven
    -> SQLite
    -> Git
    -> Github

## Development Philosophy
    Plan -> Design -> Implement -> Test -> Document


I'm developing this project as a practical software engineering 
learning project with the goal of eventually becoming production grade
software.
